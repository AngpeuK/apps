# apps

Нативное приложение для строки меню macOS, которое управляет расположением окон и записывает экран с системным звуком.

![Иконка apps](assets/apps-icon.png?v=03940cb)

## Возможности

- разворачивание, уменьшение, сворачивание и восстановление окон;
- центральное расположение окон;
- две вертикальные стопки;
- две горизонтальные панорамы;
- сетки на 4 и 8 позиций;
- переключение верхних и нижних стопок;
- адаптация раскладок к текущему разрешению и рабочей области дисплея;
- запись основного экрана с курсором и прямым системным звуком в MP4;
- запуск при входе в macOS и перезапуск приложения из меню.

## Требования

- macOS 13 или новее;
- Apple Command Line Tools (`xcode-select --install`);
- разрешение «Универсальный доступ» для управления окнами;
- разрешение «Запись экрана и системного звука» для записи.

## Сборка

```bash
./build.sh
```

Готовое приложение появится по адресу:

```text
dist/apps.app
```

Запуск:

```bash
open dist/apps.app
```

Скрипт собирает приложение системным `clang` и подписывает его локальной ad-hoc подписью с постоянным designated requirement `ee.antero.apps`.

## Запись экрана

Пункт «Начать запись экрана» использует ScreenCaptureKit и AVFoundation. Видео кодируется в H.264, системный звук — в AAC. Файлы сохраняются в папку пользователя «Фильмы». Микрофон не используется.

## Примечания

Некоторые приложения задают собственный минимальный размер окна и могут отказаться уменьшаться до размера ячейки. Защищённый DRM-контент может не попадать в запись экрана.
